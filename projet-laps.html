Présentation du projet

Windows LAPS (Local Administrator Password Solution) est une solution de sécurité Microsoft permettant de gérer automatiquement les mots de passe des comptes administrateurs locaux sur les postes de travail d'un domaine Active Directory.

L'objectif principal de ce projet est de renforcer la sécurité du parc informatique en éliminant le risque lié à l'utilisation d'un mot de passe administrateur local identique sur plusieurs machines, une pratique courante mais dangereuse en cas de compromission.

Fonctionnement de Windows LAPS

Windows LAPS génère et gère automatiquement des mots de passe uniques pour chaque poste de travail :

  • Génération automatique : Création d'un mot de passe robuste et unique pour le compte administrateur local de chaque machine
  • Rotation automatique : Renouvellement périodique des mots de passe selon une politique définie (durée de validité configurable)
  • Stockage sécurisé : Les mots de passe sont chiffrés et stockés dans Active Directory, accessibles uniquement aux administrateurs autorisés
  • Historique : Conservation d'un historique des mots de passe précédents pour faciliter les opérations de récupération

Architecture technique

Prérequis

  • Environnement Active Directory fonctionnel
  • Module PowerShell LAPS installé sur le contrôleur de domaine
  • Postes de travail sous Windows 10/11 ou Windows Server

Étapes de déploiement

  1. Mise à jour du schéma Active Directory
    • On ajoute quelques attributs dans l’annuaire pour stocker les mots de passe chiffrés et leur historique.
    • Commande PowerShell : Update-LapsADSchema
    • Vérification de la présence des attributs (msLAPS-Password, msLAPS-PasswordExpirationTime, etc.)
  2. Configuration des permissions
    • On donne aux ordinateurs le droit d’écrire leur propre mot de passe dans l’annuaire.
    • Commande : Set-LapsADComputerSelfPermission
  3. Déploiement des modèles d'administration
    • Copie des fichiers LAPS.admx et LAPS.adml dans le magasin central SYSVOL
    • Permet la configuration via stratégies de groupe (GPO)
  4. Création de la stratégie de groupe (GPO)
    • Une nouvelle GPO est créée et liée aux unités d’organisation (OU) contenant les machines à couvrir.
    • Cette GPO transporte les règles : longueur du mot de passe, caractères spéciaux, durée de validité, historique, fréquence de rotation et activation du chiffrement obligatoire.

Avantages de la solution

Sécurité renforcée :

  • Élimination du risque de propagation latérale en cas de compromission d'une machine
  • Mots de passe complexes générés automatiquement selon les exigences de sécurité
  • Chiffrement des mots de passe stockés dans Active Directory
  • Gestion simplifiée : Automatisation complète de la rotation des mots de passe, sans intervention manuelle
  • Conformité : Respect des bonnes pratiques de sécurité et des exigences réglementaires
  • Intégration native : Solution Microsoft intégrée à Windows Server et Active Directory

Résultats et impacts

Le déploiement de Windows LAPS a permis d'améliorer significativement la sécurité du parc informatique.
