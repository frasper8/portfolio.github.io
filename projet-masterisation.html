Présentation du projet

Le projet de masterisation consiste à déployer de manière automatisée Windows 11 sur un parc informatique. Contrairement aux méthodes traditionnelles de déploiement, cette approche utilise un fichier XML de réponse automatique.

Objectif principal : Automatiser l'installation de Windows 11, la configuration système, le renommage automatique des PC (format "GNEX-" + numéro de série, ex. "GNEX-6G392N"), la mise en domaine Active Directory et la désinstallation des applications non nécessaires — le tout sans intervention manuelle.

Pourquoi choisir l'ISO plutôt que l'image ?

  • Utilisation de l'ISO officiel Microsoft toujours à jour — pas besoin de recapturer une image
  • Facilité de modification du XML sans recréer une image complète du système
  • 15 minutes pour un déploiement ISO contre 1 à 2 heures pour le déploiement d'image

Processus de déploiement

  1. Téléchargement de l'ISO Windows 11 officiel
  2. Configuration du fichier de réponse via le site Schneegans incluant tous les paramètres d'installation
  3. Utilisation d'AnyBurn pour modifier l'ISO et intégrer le fichier Unattend.xml
  4. Boot du PC cible depuis le réseau via Iventoy ou un support USB — installation démarre automatiquement
  5. Windows 11 s'installe sans intervention, applique toutes les configurations définies dans le XML
  6. Le poste rejoint automatiquement le domaine Active Directory avec les identifiants configurés via PowerShell

Configuration du fichier Unattend.xml

Le fichier Unattend.xml a été généré via le site Schneegans et contient l'ensemble des paramètres nécessaires pour automatiser l'installation de Windows 11 (~600 lignes de configuration).

Paramètres principaux configurés :

  • Paramètre Windows PE : séléction des disques, clé de licence, acceptation des CGU, prérequis windows 11.
  • Paramètre Specialize : Déclaration, dans l'ordre, des différents scripts de personalisation de windows.
  • Paramètre OOBE : Langue et région, clavier, création de compte utilisateur, paramètre de confidentialité, acceptation des termes de licence.
  • Personalisation systèmes à travers des scripts PowerShell :
    • Renommage automatique : format "GNEX-" + numéro de série
    • Jonction automatique au domaine Active Directory INNOVATECH.LOCAL
    • Désinstallation automatique des applications non nécessaires
    • Désactivation des écrans OOBE (Out-of-Box Experience)
